## 一、它是什么

一个**独立的网络诊断与 Windows 优化工具**，双击就能用，可以和别的工具箱放在同一个目录共存。
它不修改同目录下任何其它程序的文件，也不会被它们的更新覆盖。

```
<你放工具的目录>\
├── 夕颜若雪网络工具.exe       ← 本工具
├── 网络工具-使用说明.md
├──（同目录下的其它程序，本工具不会去动）
├── .runtime\    ← 首次运行自动生成，存放内嵌脚本
├── logs\        ← 本工具的日志（每天一个文件）
└── backup\      ← 改动前的状态快照，可对照回滚
```

**首次运行会弹 UAC，请点「是」。** 修复和优化功能需要管理员权限，
（程序清单里已声明 requireAdministrator，所以每次都会自动申请）。

## 二、八个页面

左侧导航：**概览 / 网络检测 / 断网修复 / 网络优化 / 运行日志**

### 1. 概览

打开就看到当前状态：活动网卡数量、默认网关、DNS、系统代理。
四个快捷按钮直接跳到对应功能。首次使用建议先点「一键网络体检」。

### 2. 网络检测（只读，绝对安全）

不做任何修改，只做体检。检测顺序是**分层定位**，一眼看出断在哪一层：

| 检测项 | 说明 |
|---|---|
| 活动网卡 | 列出真正在用的有线/无线网卡及其 IP、掩码、网关、DNS、获取方式 |
| 本机协议栈 | TCP/IP 是否正常 |
| 默认网关 | 内网通不通（不通 = 网线/路由器问题） |
| 外网 IP 可达 | 网关通但这里不通 = 宽带/上级路由问题 |
| DNS 域名解析 | 能上 IP 不能开网页 = DNS 问题 |
| HTTP 出网 | 真正拉一次网页，最接近真实体验 |
| DNS 实测 | 把你机器上配置的每个 DNS 挨个测一遍响应时间 |
| 系统代理 | **带探测**：如果代理指向 127.0.0.1 且端口不通，会直接告诉你"这就是打不开的原因" |
| WinHTTP 代理 | Windows 更新/服务走的代理通道 |
| hosts / Winsock / 服务 / 防火墙 / 默认路由 | 常见的隐性故障点 |
| 网卡节能 | 「允许计算机关闭此设备以节约电源」会导致随机掉线 |

> 检测中行右侧显示耗时与结论，绿色=正常，黄色=建议处理，红色=异常。
> 底部「结论」一行会直接告诉你要不要修。

**按钮**：开始全面检测 · 导出报告 · 复制摘要 · 去修复
**标签页**：检测结果 / 网卡信息 / DNS 实测 / 原始信息（原始信息含 `ipconfig /all`、
路由表、TCP 参数、防火墙、连接数 TOP 进程，可直接复制发给别人看）

### 3. 断网修复

三个层级，从轻到重：

**① 一键断网修复**（推荐，安全无副作用）
按顺序执行：刷新 DNS → 修复 169.254 无效地址 → 清空 ARP/邻居缓存 →
关闭并重置系统代理 → 拉起网络服务。

**② 修复项（可单独勾选执行）**
10 个可选动作：
- 刷新 DNS 缓存 + 重新注册
- 重新获取 IP 地址（DHCP，会断 3~10 秒）
- 清空 ARP / 邻居缓存
- 关闭并重置系统代理
- 修复网络相关服务（Dhcp / Dnscache / NlaSvc / netprofm / WlanSvc / WinHttpAutoProxySvc / nsi / Netman / Wcmsvc）
- 修复 169.254 无效地址
- 还原 hosts 文件为默认（会先备份）
- 重置 Winsock 目录（**需重启**）
- 重置 TCP/IP 协议栈（**需重启**）
- 重置防火墙为默认（慎用，会删自定义规则）

**③ 快速处置**（按症状点一下）
- 网页打不开 / 能上 QQ 不能上网 → 刷新 DNS
- 代理软件关了以后全网打不开 → 清系统代理 + WinHTTP 代理
- 右下角感叹号 / 无 Internet 访问 → 拉起网络服务
- IP 是 169.254.x.x → 重新获取 IP
- 改了 hosts 后网站打不开 → 备份并还原 hosts

**④ 深度修复**（需重启）
Winsock + TCP/IP 协议栈重置 + hosts 还原 + 上述全部。
会弹确认框，完成后可一键重启（15 秒倒计时，`shutdown /a` 可取消）。

> 每次修复前都会把当前状态写进 `backup\backup.ini`：
> 系统代理、WinHTTP 代理、TCP 全局参数、每块网卡的 IP/网关/DNS、默认路由，
> 以及单独的 hosts 备份。出问题可以照着重设回去。

### 4. 网络优化

**DNS 择优加速**
点「开始 DNS 测速」并发实测 12 个公共 DNS（阿里、腾讯、114、百度、CNNIC、360、
Google、Cloudflare、Quad9）的真实解析速度，按快慢排序。
然后「应用最快 DNS」或「应用最快前两个」，一键写进所有活动网卡（改前自动快照）。
也可以自己填：「自定义 DNS」输入框填 `223.5.5.5,114.114.114.114` 点应用。
「恢复自动获取DNS」可还原成 DHCP 下发的 DNS。

**TCP 参数调优**
左侧表格实时显示 TCP 全局参数，按钮：
- **响应优先** —— 降低延迟，适合游戏 / 远程桌面 / 网页
- **吞吐优先** —— 适合下载 / 大文件传输
- **还原默认** —— 恢复 Windows 出厂参数
- **关闭网卡节能** —— 关掉「允许计算机关闭此设备以节约电源」和节能以太网，治随机掉线
- **看谁在占网速** —— 按 TCP 连接数排出 TOP 15 进程（含 PID 和完整路径）

内置 **151 项 Windows 优化**（配置源自 ZyperWin++ 的声明式优化表，含官方还原方案），
按 7 个分类分标签页展示：

| 分类 | 条数 | 内容 |
|---|---|---|
| 性能优化 | 45 | HPET、处理器性能、预读、幽灵熔断补丁、GPU 加速、SysMain/Search |
| 外观 / 资源管理器 | 29 | 任务栏、右键菜单、扩展名、快速访问、崩溃自动重启 |
| 隐私保护 | 34 | 遥测、活动收集、广告 ID、诊断数据上报 |
| 系统设置 | 14 | 休眠、蓝屏行为、磁盘检查、还原点、字体 |
| Edge 浏览器 | 12 | 后台常驻、启动增强、必应广告、诊断数据 |
| Windows 更新 | 7 | 驱动更新、大版本更新、恶意软件删除工具 |
| 安全设置 | 10 | UAC / SmartScreen / 防火墙 / 内存完整 / 虚拟化安全 |

**每行显示**：勾选框 · 优化项名称 · **状态**（已优化 / 未优化 / 状态未知）· **当前值**
状态是实时读注册表判定的，打开就能看到本机哪些项已经优化过（绿色=已优化，黄色=未优化）。

**⚠ 红色项**是降低系统防护的（关闭防火墙、关内存完整性、关虚拟化安全、UAC 从不通知等），
默认不勾选，鼠标悬停有提示。「只选推荐项」按钮会一键勾选全部非风险项。

**按钮**：
- **应用勾选项** —— 弹窗列出风险项确认 → 写快照 → 逐项执行 → 广播设置变更
- **还原勾选项** / **全部还原** —— 按配置声明的官方还原方案恢复为 Windows 默认
- **全选本页 / 全不选 / 只选推荐项 / 重新检测状态**
- **打开快照目录** —— 查看优化前的注册表原值记录

**执行完成后**会询问是否重启资源管理器，让任务栏、右键菜单、主题类改动立即生效。
涉及服务、电源、休眠的项需要注销或重启后完全生效。

> 优化前的注册表原值会全部记进 `backup\backup.ini`，出问题可以照着改回去。

### 6. 系统工具

五个子标签页（对应 ZyperWin++ 的 Clean / Appx / Defender+服务 / 启动项 / Activate）：

#### ① 垃圾清理
**24 个清理目标**，分 5 组，勾选后点「扫描占用」会实时算出每项占多少，再「开始清理」。
默认只勾选安全项（临时文件、缓存、日志、错误报告），危险项默认不勾：
- ⚠ **回收站**（默认不勾，另有「同时清空回收站」开关，会二次确认）
- ⚠ **.NET NativeImages 缓存**（默认不勾 —— 删掉后 .NET 程序首次启动会变慢，Windows 会自动重建）
- Windows 更新缓存、传递优化缓存、WinSxS、minidump、memory.dmp、Defender 扫描记录（默认不勾）

含 2 个命令类项：`dism /Online /Cleanup-Image /StartComponentCleanup`（清理 WinSxS 组件）、
`ipconfig /flushdns`。被占用的文件会自动跳过并如实报告，不会卡死。

> 本工具**不会**删掉自己的日志目录，方便事后排查。

#### ② 应用管理
列出全部 Appx 应用（`IsFramework` 已过滤），**带真实占用大小，按大小倒序**。
可勾选多个批量卸载，会同时移除预装包（`Remove-AppxProvisionedPackage`），
卸载后复核确认是否真的消失。系统不可移除的应用禁选。
> 你机器上实测：**108 个应用，合计 5.77 GB**（照片 878 MB、奥创 674 MB、截图 585 MB…）

#### ③ 系统服务
枚举全部服务，带**真实启动类型**（直接读 `Start` 值：自动/手动/禁用/延迟自动）、运行状态、可执行路径。
可启动/停止/设为自动/手动/禁用。默认只显示第三方服务，可勾选显示微软服务。
内置「**禁用推荐项**」：20 个可安全禁用的服务（遥测、错误报告、远程注册表、传真、
Xbox、地图、传感器、家长控制等），逐个列出用途后再确认，不存在的自动跳过。

#### ④ 启动项
- **注册表 Run/RunOnce**（HKCU + HKLM + WOW6432Node 三个视图）
- **启动文件夹**（当前用户 + 所有用户）
- **计划任务**（点「加载计划任务」按需枚举，256 条实测；系统任务灰显不可禁用）

禁用用的是 **Windows 官方 StartupApproved 机制**（任务管理器同款），
所以**不改动原始注册表项**，随时可以一键恢复；启动文件夹项则是改名加 `.disabled` 后缀。
都会读取真实启用/禁用状态显示在「状态」列。

#### ⑤ 系统激活
**不内置激活脚本**。会自动在你指定的位置搜索 `MAS_AIO_CN.cmd`
（工具所在目录 / `D:\github\Release\Bin\` / `D:\github\Release\`），
找到后可一键调用（弹出独立命令行窗口）。另有「查看当前激活状态」调用 `slmgr /dli`。

### 7. 硬件检测

四个子标签页，对应图吧工具箱的硬件检测 + 工具集：

#### ① 硬件信息
一键读取全机硬件，**全部来自 WMI/CIM 与注册表，本机采集，不依赖任何外部程序、不上传任何数据**：

| 项目 | 内容 |
|---|---|
| 系统 / 整机 | 操作系统与版本、架构、计算机名、整机品牌型号、**主板厂商与型号**、BIOS 版本与日期、主板序列号、SMBIOS UUID、安全启动、内存总量、安装时间、运行时长 |
| 处理器 | 型号、厂商、**核心/线程**、主频（最大/当前/外频）、L2/L3 缓存、封装、虚拟化支持、实时负载 |
| 内存 | 每条的品牌、型号、容量、**类型（DDR4/DDR5 自动识别）**、频率、实际运行频率、电压、DIMM/SODIMM，并自动判断**单通道/双通道** |
| 显卡 | 型号、**显存**、驱动版本与日期、当前分辨率与刷新率 |
| 硬盘 | 型号、序列号、容量、接口、**健康状态、温度、通电小时数、磨损度**（SMART） |
| 分区 | 每个分区的文件系统、总容量、可用空间、使用率（超过 92% 会警告） |
| 显示器 | **面板型号、厂商代码、生产年月、序列号、物理尺寸与英寸数**（读 EDID） |
| 网卡 / 声卡 / 电池 / 温度 | 适配器与状态、声卡、电池健康度与循环次数、ACPI 温度区 |

**按钮**：`开始检测`（10 分钟内走缓存）、`复制报告`、`导出到文件`、
`导出为任务管理器截图友好格式`（切换紧凑格式，适合发帖问配置）。

> 显存特意从注册表 `HardwareInformation.qwMemorySize` 读 —— WMI 的 `AdapterRAM` 是 32 位，
> 8GB 显卡会被截断成 4GB（这是老检测软件报错显存的经典原因）。

#### ② 工具启动器
自动定位图吧工具箱的 `tools` 目录（`D:\github\图吧工具箱*\tools` 等常见位置），
扫描出全部工具，按分类列出「分类 / 工具 / 可执行文件 / 目录」，双击即启动。

- 实测扫出 **87 个工具**：硬盘 20、其他 17、游戏 10、处理器 9、内存 7、外设 7、显卡 7、综合检测 5、显示器 3、烤鸡 2
- 支持搜索框过滤、`打开所在目录`（资源管理器定位到 exe）、`打开 tools 目录`
- **直接调用图吧原版工具**（CPU-Z、AIDA64、CrystalDiskInfo、FurMark、TM5、WizTree…），
  本工具不复制、不修改任何第三方程序

#### ③ 性能测试
自带跑分，全部本机实测：

- **CPU 跑分（约 15 秒）**：SHA256 单线程/多线程吞吐 + 浮点运算，
  给出**多线程加速比**，用来判断多核调度是否正常、是否被功耗墙限制（实测本机：单线程 2031 MB/s、多线程 19841 MB/s、加速比 9.8×）
- **磁盘测速（256MB）**：顺序写入 + 顺序读取，临时文件自动删除（实测本机：写 1634 MB/s、读 4834 MB/s）
  - ⚠ 固态硬盘测速会产生写入量，不必频繁测
  - 随机 4K 性能请用工具启动器里的 CrystalDiskMark / AS SSD

#### ④ 屏幕测试
全屏显示，**按 ESC 或点击退出**：

- 纯白（查黑点/灰尘）、纯黑（查亮点与漏光）、纯红/纯绿/纯蓝（查色偏与坏点）
- 灰阶渐变（32 级灰阶 + 连续渐变，查色带 banding）
- 网格测试（40px / 10px / 1px 三级，点一下切换，查几何失真、边缘对焦、摩尔纹）
- 文字清晰度测试（多字号多字体，查发虚与彩边）
- 一键打开 UFO 高刷测试、在线屏幕测试（网页）

### 8. 运行日志

界面上的全部动作都记在这里，同时写入 `logs\NetDoctor_YYYYMMDD.log`。
可打开日志文件/目录、复制全部、清空显示。**出问题把日志发出来就能定位。**

## 三、典型排查流程

**想要一台上手就顺滑的 Windows**
1. 概览 →「Windows 全推荐项」→ 自动跳到 Windows 优化页并勾好全部推荐项
2. 检查一遍列表（红色项不会被勾上）
3. 点「应用勾选项」→ 确认 → 等完成
4. 弹窗问是否重启资源管理器 → 点「是」
5. 不满意就回来点「还原勾选项」

**C 盘满了 / 想清空间**
1. 系统工具 → 垃圾清理 →「只选推荐项」
2. 点「扫描占用」看每项多少（有几 GB 是正常现象）
3. 「开始清理」（回收站和 .NET 缓存默认没勾，想清再单独勾）
4. 还不够就去「应用管理」按大小排序，卸载用不到的应用
5. 再不够就把页面拉到「Windows 优化 → 系统设置」，启用「关闭休眠」（省出与内存等大的 hiberfil.sys）

**想看清这台机器是什么配置 / 值不值这个价**
1. 硬件检测 →「开始检测」→ 看 CPU 型号、内存是单通道还是双通道、显卡显存有没有被阉割
2. 点「导出为任务管理器截图友好格式」，直接复制发出去问配置
3. 顺便看硬盘健康度和通电时间 —— 买二手盘/二手整机必看
4. 想跑个分对比，去「性能测试」跑 CPU 和磁盘

**突然上不了网**
1. 打开本工具 → 概览看有没有网卡
2. 「一键网络体检」→ 看红色项断在哪一层
   - 网关就不通 → 查网线/无线开关/路由器
   - 网关通、外网不通 → 宽带问题或代理问题
   - 外网通、DNS 红 → DNS 问题
3. 点「去修复」→「一键断网修复」
4. 还不行 →「深度修复」+ 重启

**能上 QQ 但网页打不开**
→ 断网修复 →「一键断网修复」，或直接点快速处置里的第一条。

**开了代理软件又关掉之后全网打不开**
→ 断网修复 →「关闭并重置系统代理」。本工具在检测页就会提前警告这一条。

**网速慢**
→ 网络优化 → DNS 测速 → 应用最快 DNS；顺便「看谁在占网速」。

**网络时通时断**
→ 网络优化 →「关闭网卡节能」；再检测页看有没有多条默认路由。

## 四、安全说明

- **网络检测**只读，不改任何设置，随便点。
- **所有写操作**前都会生成 `backup\backup.ini` 快照和 hosts 备份；
  Windows 优化的每一项还会额外记录**优化前的注册表原值**。
- **重置 Winsock / TCP-IP** 后必须重启才完全生效，重启前网络可能不稳定。
  （这是 Windows 的机制，不是本工具的问题）
- **重新获取 IP** 会短暂断网 3~10 秒。
- **重置防火墙**会删除自定义规则，默认不勾选。
- **Windows 优化**里的红色项（关防火墙、关内存完整性、关虚拟化安全、UAC 从不通知）
  会实际降低系统防护，默认不勾选，请确认清楚再动。
- 程序**未做任何联网上传**，DNS 测速是直接向 DNS 服务器发 UDP 查询，不经过任何第三方。
  没有任何遥测、没有回传。
- 日志只写在本地 `logs\` 目录。
- **优化配置是编译进 exe 的**，运行时不读取 `D:\github\Release`，也不依赖任何外部文件。
  原 ZyperWin++ 目录可以随意移动或删除。

## 五、与 ZyperWin++ 的关系

`<Restore>` 还原方案），解析和执行引擎是我自己实现的。151 条优化项之外的其它功能

是**读懂它的反编译源码后按同样行为重写**的。

- **没有**调用、加载或修改 `ZyperWin++.exe`（它是 .NET 4.7.2 + AntdUI，也无法直接嵌入）
- **没有**打包它的 `Bin\` 脚本
- 优化配置**编译进 exe**，运行时不读 `D:\github\Release`，也不依赖任何外部文件

**刻意不做**的高破坏性功能（原 ZyperWin++ 有，本工具不提供自动调用）：

- 停止 Windows 更新到 2999 年
- Windows 激活（只做"找到脚本并帮你启动"，不内置脚本）

需要这些请直接运行原 ZyperWin++ 目录里的 `Bin\Edge`、`Bin\Update`、`Bin\UnInstallC2R.vbs`

## 六、与图吧工具箱的关系

「硬件检测」页的两部分来源完全不同：

- **硬件信息 / 性能测试 / 屏幕测试**：**完全自己实现**。
  图吧工具箱的硬件数据库（`List\*.edb`、`data\*.edb`）是加密的
  （magic `WCDB`，熵 8.00，主程序还加了壳），拿不到也解不开，所以没有抄任何数据。
  这里的 CPU/主板/内存/硬盘/显示器信息全部来自 Windows 自带的 WMI/CIM 与注册表，
  部分细节（显存、EDID、SMART）走注册表和 root\wmi 命名空间。
- **工具启动器**：**只做启动，不复制不修改**。
  它扫描 `D:\github\图吧工具箱202608\tools` 目录，列出原版 exe 并直接调用，
  所有第三方工具（CPU-Z、AIDA64、FurMark…）仍然是图吧工具箱自带的那份。

图吧工具箱本身的启动器、皮肤、天梯图、加密数据库这些没有移植，
需要那个界面的话直接用原版即可。

## 七、常见问题

**Q: 双击没反应 / 一闪而过？**
A: 看 `logs\` 下最新日志；另外确认杀软没有拦截（本工具会调用 netsh/ipconfig/gpupdate，
属于正常系统命令，但个别杀软会提示）。

**Q: 界面字有点糊？**
A: 程序使用系统 DPI 缩放（不做 Per-Monitor 感知），在 125%/150% 缩放屏上
Windows 会做位图拉伸。这样能保证窗口尺寸和控件布局在任何缩放比例下都不会错位。
如果确实需要清晰字体，可以在 exe 属性 → 兼容性 → 更改高 DPI 设置 →
勾选「替代高 DPI 缩放行为」，选「应用程序」。

**Q: 优化后任务栏/右键菜单没变化？**
A: 界面类改动需要重启资源管理器。执行完成后弹窗会问你要不要重启，点「是」即可；
也可以手动 `taskkill /f /im explorer.exe & start explorer.exe`。

**Q: 某项显示「状态未知」？**
A: 那是「去除本地磁盘重复显示」这一项 —— 它的判定条件是整个注册表键是否存在，
不是某个值，所以无法自动判定当前状态。勾选后照样能执行。

**Q: 优化错了怎么恢复？**
A: 回到 Windows 优化页，勾上那几项点「还原勾选项」（按官方还原方案恢复）；
或者打开 `backup\backup.ini` 照着「优化前原值」手动改回去。
「全部还原」会把 151 项一次性恢复成 Windows 默认。

**Q: 垃圾清理会不会误删东西？**
A: 只删缓存、临时文件、日志、错误报告这几类，全部是 Windows 会自动重建的内容。
回收站和 .NET NativeImages 缓存默认不勾（前者不可恢复，后者删了会让 .NET 程序首次启动变慢）。
正在被占用的文件会自动跳过；回收站清理前会额外弹一次确认。

**Q: 应用卸载了想装回来怎么办？**
A: 卸载的是 Appx 应用（照片、计算器、终端之类），本工具无法恢复，
需要到 Microsoft Store 搜索同名应用重新安装。卸载前会弹窗列出清单让你确认。

**Q: 禁用启动项后想恢复？**
A: 回到「启动项」页，选中那一行点「启用选中」即可。用的是 Windows 官方
StartupApproved 机制，原始注册表项没动过，也可以直接在任务管理器里恢复。

**Q: 硬件检测显示「读取失败」或数据不对？**
A: 笔记本的显存、部分温度传感器、部分品牌机的序列号在 WMI 里就是空的，属于系统限制。
如果整页都读不出来，看日志里 `sysitems.ps1` 的报错；常见原因是杀软拦截了 PowerShell 调用。

**Q: 工具启动器扫不到工具？**
A: 它会按顺序找 `D:\github\图吧工具箱*\tools`、`C:\图吧工具箱\tools`、`D:\图吧工具箱\tools`、
`E:\图吧工具箱\tools`，再扫各盘符下名字含「图吧」的目录。都不在的话点「打开 tools 目录」
确认路径，或直接把图吧工具箱放在上述位置。

**Q: 屏幕测试点进去全屏了怎么退出？**
A: 按 ESC，或者用鼠标点一下画面。网格测试点了会切换三级网格，点第三次退出。

**Q: 和工具箱能联动吗？**
A: 现在两条路子都通：
1. 现在就是**放在同一目录的独立工具**，各自启动即可。
2. 下一步可以把功能编译成标准 `__stdcall` 导出 DLL，
   由工具箱（易语言）用 `LoadLibrary` + 调用子程序 的方式调起来，
   直接长在它的界面里。需要配合易语言源码或二进制补丁，属于下一阶段。
